# Final Demonstration Script

Use real/safe test records imported through the production CSV path.

1. Open IntelliLib on Student PC.
2. Click Student and scan the registered test student ID using the in-app camera.
3. Search a real imported book by title/author/ISBN.
4. Open it and request it.
5. On Admin PC, open Requests and approve.
6. Student receives the approval notification live.
7. Admin opens Issue / Return → Issue Book.
8. Scan the same student ID.
9. Scan the exact physical test-book barcode.
10. Show Student → My Books with copy barcode and due date.
11. Admin → Return Book → scan student ID → scan the same copy.
12. Show availability restored and student notification.
13. Briefly explain Search/DSA internals from `DSA_USAGE.md`, not from the normal app UI.
